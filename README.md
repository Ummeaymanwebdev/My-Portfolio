# My Portfolio (Next.js + Tailwind CSS)

## Run it
1. Open this folder in VS Code
2. Terminal: `npm install`
3. Terminal: `npm run dev`
4. Open http://localhost:3000

## Edit your information
Everything (name, about text, skills, education, projects, links) is in `data/site.js`.

## Replace the placeholders
- Your photo: put `photo.jpg` in `public/` and set `photo: "/photo.jpg"` in `data/site.js`
- Project screenshots: put them in `public/projects/` and change each project `image` path
- Resume: replace `public/resume.pdf` with your final PDF (keep the same name)

## Deploy
Push to GitHub, then import the repo on vercel.com and click Deploy.
